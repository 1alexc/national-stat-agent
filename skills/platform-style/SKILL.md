# Platform Style

Each platform has its own rules. Identify the target platform, then read the
matching reference file before drafting:

- X (Twitter) — **default for UK ONS statistical posts unless another platform is requested**: read `references/x.md`
- LinkedIn: read `references/linkedin.md`

If the user has not named a platform, default to **X (Twitter)** for UK statistics posts (or ask if they are writing a general non-statistical post).
